# Banco de Copys y Estrategia de Copywriting — ALPACLADD

Guía práctica de redacción para el Community Manager. Incluye la fórmula de redacción oficial, banco de plantillas de copy listas para usar y clusters de hashtags.

---

## 1. La Fórmula de Redacción ALPACLADD (H.E.C.A.)

Cada publicación de feed o video reel debe respetar esta estructura de 4 pasos:

1. **H (Hook / Gancho de Alto Impacto):** Una pregunta técnica o afirmación que frena el scroll en los primeros 2 segundos.
2. **E (Educación / Desarrollo Técnico):** Explicación concreta con datos reales (TPM, título de hilo, micrones, velocidad de huso).
3. **C (Conversión / CTA Directo):** Llamado a la acción claro (descargar ficha, solicitar muestra técnica, comentar, enviar DM).
4. **A (Aterrizaje con Hashtags):** Bloque optimizado de 5 a 8 hashtags segmentados.

## 4. Política de Uso de Emojis

### Emojis Aprobados (Uso Profesional Sobrio):
- 🧵 🧶 (Hilado / Tejido / Textil)
- 🏭 ⚙️ ⚡ (Industria / Maquinaria / Precisión)
- 🔹 📌 (Puntos de viñeta técnicos)
- 🌱 ♻️ 🌿 (Línea sustentable ECO-SPUN)
- 🤝 👥 (Equipo comercial y clientes)

### Emojis Prohibidos (Evitar en Canales Oficiales):
- ❌ 🤪 🥳 💥 🤑 🚀🔥 (Excesos informales o sensacionalistas que resten seriedad industrial).
