# 📚 Manual de Marca Oficial — ALPACLADD
### Carpeta Maestra de Recursos y Guías para Community Managers, Diseñadores y Marketing

Bienvenido al repositorio oficial del **Manual de Marca de ALPACLADD (Fábrica de Hilados)**. Esta carpeta contiene todos los lineamientos normativos, archivos vectoriales, códigos de color, copys, protocolos de atención al cliente y mockups necesarios para gestionar la identidad visual y la comunicación en redes sociales.
